# Waterberg Cartography Project

This repository contains the working files for the **Waterberg Cartography project**, a collaboration between Kartoza and Waterberg Tourism.

## Overview

The project builds on earlier mapping work completed for Waterberg Tourism and aims to produce updated maps that can support both print and digital use.

## Current Scope

* Gather and review existing mapping assets.
* Define the geographic areas of focus around the main towns.
* Prepare proof-of-concept (PoC) maps for stakeholder review.
* Lay the groundwork for future digital and web-friendly map formats.

## Partners & Stakeholders

* [**Kartoza**](https://kartoza.com) – GIS and cartographic support
* [**Waterberg Tourism**](https://waterbergtourism.com) – Regional knowledge and coordination
* [**Essential Marketing**](https://www.essentialmarketing.co.za) – Brochure design and distribution

## Status

User requirements and scope are currently under review. This repository will be updated as the project progresses.
